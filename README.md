# SATD Detection Pipeline
**Deep Learning and Data Augmentation for Detecting Self-Admitted Technical Debt**
*Sutoyo et al., 2024 — arXiv:2410.15804v1*

---

## Overview

This project replicates the two-step SATD detection pipeline from the paper:

```
Raw Text
   │
   ▼
[01_preprocessing.py]          — Clean, tokenize, lemmatize all four artifacts
   │
   ▼
[02_bilstm_identification.py]  — Step 1: BiLSTM binary classification (SATD vs Not-SATD)
   │
   ▼ (SATD only)
[03_bert_classification.py]    — Step 2: BERT multi-class categorization (C/D, DOC, TES, REQ)
   │
   ▼
[04_prediction_pipeline.py]    — Combined two-step inference on new text
```

## Setup

### 1. Install Dependencies

```bash
pip install torch transformers scikit-learn pandas numpy nltk
```

### 2. Download GloVe Embeddings (for BiLSTM)

```bash
# Download GloVe 6B 100d (~800MB)
wget http://nlp.stanford.edu/data/glove.6B.zip
unzip glove.6B.zip -d data/
# You only need: data/glove.6B.100d.txt
```

### 3. Place Data Files

Copy the four CSV files into the `data/` directory:
- `data-augmentation-code-comments.csv`
- `data-augmentation-commit-messages.csv`
- `data-augmentation-issues.csv`
- `data-augmentation-pull-requests.csv`

**Expected CSV columns:** `text` (or `comment`/`message`/`body`) and `label`

**Label values:**
- `Not-SATD` — not self-admitted technical debt
- `C/D` — code/design debt
- `DOC` — documentation debt
- `TES` — test debt
- `REQ` — requirement debt

## Step-by-Step Usage

### Step 1 — Preprocessing

```bash
python 01_preprocessing.py
```

Applies the full preprocessing pipeline from paper Section III-D:
- Lowercase conversion, URL removal, non-ASCII removal
- Number removal, punctuation removal, whitespace normalization
- Tokenization, stop word removal, short word removal (≤2 chars), lemmatization

Creates `data/preprocessed/preprocessed_{cc,cm,is,ps}.csv` with columns:
- `original_text` — raw input
- `cleaned_text` — preprocessed text
- `label` — original multi-class label
- `binary_label` — `SATD` or `Not-SATD` (for BiLSTM)

---

### Step 2 — BiLSTM Identification

**Train on a single artifact:**
```bash
python 02_bilstm_identification.py --artifact CC --mode train
```

**Train with AugGPT-augmented data:**
```bash
python 02_bilstm_identification.py --artifact CC --mode train --use_augmented
```

**Train all four artifacts:**
```bash
python 02_bilstm_identification.py --artifact all --mode train
```

**Evaluate a saved model:**
```bash
python 02_bilstm_identification.py --artifact IS --mode evaluate
```

**All command-line arguments:**
```
--artifact        {CC, IS, PS, CM, all}   Artifact to process (default: all)
--mode            {train, evaluate}        Run mode (default: train)
--data_dir        Path to preprocessed CSVs
--glove_path      Path to GloVe .txt file
--embedding_dim   GloVe dimension (default: 100)
--max_seq_len     Max token sequence length (default: 200)
--batch_size      Training batch size (default: 64)
--epochs          Max training epochs (default: 50)
--patience        Early-stopping patience (default: 5)
--use_augmented   Include augmented training data
--output_dir      Results directory (default: results/)
--model_dir       Model checkpoint directory (default: models/)
```

**Results saved to:** `results/bilstm_command_arguments.txt`

**Models saved to:**
- `models/bilstm_{ARTIFACT}.pt` — best model weights
- `models/bilstm_{ARTIFACT}_vocab.json` — vocabulary (needed for prediction)
- `models/bilstm_{ARTIFACT}_config.json` — hyperparameters (needed for prediction)

### Step 4 — Prediction Pipeline

**Predict a single text string:**
```bash
python 04_prediction_pipeline.py \
    --text "TODO: this is a hack, needs refactoring" \
    --artifact CC
```

**Predict from a CSV file:**
```bash
python 04_prediction_pipeline.py \
    --input_csv data/new_issues.csv \
    --text_col  text \
    --artifact  IS \
    --output_csv results/predictions.csv
```

**Run all four artifact models on the same input:**
```bash
python 04_prediction_pipeline.py \
    --input_csv data/mixed.csv \
    --artifact  all
```

**All command-line arguments:**
```
--artifact           {CC, IS, PS, CM, all}  Model to use (default: CC)
--input_csv          Path to input CSV file
--text               Single text string to predict
--text_col           Text column in CSV (default: text)
--output_csv         Output CSV path (default: results/predictions.csv)
--model_dir          Models directory (default: models/)
--bilstm_threshold   SATD probability threshold (default: 0.5)
--no_preprocess      Skip text preprocessing
```

**Programmatic use:**
```python
from 04_prediction_pipeline import predict

# Single text
df = predict("TODO: fix this ugly hack", artifact="CC")
print(df[["bilstm_label", "bert_category"]])

# Multiple texts
df = predict(["TODO: refactor", "Fixed typo"], artifact="IS")
```

**Output CSV columns:**
```
original_text | preprocessed_text | bilstm_label | bilstm_confidence | bert_category | bert_confidence
```

## Model Architecture

### BiLSTM (Identification — Step 1)
*Paper Section III-F*

```
Embedding(vocab_size × 100, GloVe pre-trained)
    → BiLSTM(128) → Dropout(0.3) → BatchNorm
    → BiLSTM(64)  → Dropout(0.3)
    → BiLSTM(128) → Dropout(0.3)
    → BiLSTM(128)                  [final]
    → Linear(256 → 2) → Softmax
```
- Loss: CrossEntropyLoss
- Optimizer: Adam (lr=1e-3)
- Early stopping on validation loss

### BERT (Categorization — Step 2)
*Paper Section III-G*

```
bert-base-uncased (768 hidden, 12 layers, 110M params)
    [CLS] pooler output (768)
    → Linear(768 → 256) → ReLU → Dropout(0.1)
    → Linear(256 → 4)
```
- Loss: CrossEntropyLoss
- Optimizer: AdamW (lr=5e-5, eps=1e-8, weight_decay=0.01)
- Scheduler: Linear warmup (10%)
- Early stopping on validation loss

## Data Augmentation Note

The paper uses **AugGPT** (ChatGPT-3.5) for data augmentation to address class imbalance.
Place augmented CSV files as `data/augmented_{cc,cm,is,ps}.csv` and pass `--use_augmented`
when training to include them in the training split.

Augmentation targets per artifact (CM example from paper Table II):
- C/D: no augmentation (already largest class)
- DOC: ×4
- TES: ×8
- REQ: ×18
